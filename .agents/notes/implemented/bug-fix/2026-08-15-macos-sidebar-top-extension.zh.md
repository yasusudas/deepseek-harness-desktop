# Agent Note: macOSのサイドバー色をタイトルバー余白へ延長する

Status: implemented

[English](2026-08-15-macos-sidebar-top-extension.md) | 中文

## 问题

Electron包装器为了给隐藏的macOS标题栏交通灯留出空间，会增加18px的顶部内边距。信号按钮上移后，这段内边距使用整页白色背景，导致侧边栏上方出现明显的水平接缝。

## 决策

注入的macOS拖拽区域脚本会为内边距中属于侧边栏的部分创建一个不接收指针事件的固定色块。脚本从已交付的侧边栏列`[class*="_sidebarCol"]`读取位置、宽度、填充色和右边框，并通过`ResizeObserver`、DOM变化和窗口大小变化同步这些值。色块位于拖拽区域下方，其余内边距仍保持白色。

## 考虑过的替代方案

**用伪元素延伸侧边栏根元素。** 否决：布局中的侧边栏列和框架都会裁剪溢出内容，因此放到18px内边距上方的内容会被裁掉。

**把整段内边距都设为侧边栏填充色。** 否决：中心列和详情列仍使用独立的页面背景，整宽填充只会把接缝移动到错误的列。

**硬编码展开和折叠后的宽度。** 否决：侧边栏支持调整大小，而且折叠与展开期间网格轨道会做动画。

## 后果

侧边栏上方的内边距现在使用与侧边栏相同的填充色和边框，并会在调整大小、展开和折叠期间跟随其宽度变化。该选择器有意依赖固定UI bundle所交付的CSS模块后缀；如果bundle更改侧边栏列的class后缀，就必须同步更新Electron注入逻辑。

注入脚本已经通过Node语法检查、空白检查，以及覆盖位置、宽度、填充色和边框同步的DOM stub检查。打包后的`app.asar`已安装到`/Users/ichi/Applications/DeepSeek Harness.app`并验证SHA-256一致；窗口截图确认展开时填充色延伸到顶边，折叠后也会跟随紧凑侧栏宽度。
